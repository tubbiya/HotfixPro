CorelCPG Full Form Project

Usage:
1. Open CorelCPG.sln with Visual Studio 2022.
2. Open CorelCPG.rc in Resource Editor to drag & drop UI controls.
3. Add code for each control in dialog.cpp (DialogProc).
4. Make sure CorelDRAW X8 is installed and VGCoreAuto.tlb path in app.cpp is correct.
5. Build and run (F5).
