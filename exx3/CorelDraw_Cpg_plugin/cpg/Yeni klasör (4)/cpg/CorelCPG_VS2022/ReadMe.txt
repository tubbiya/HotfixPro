CorelCPG Visual Studio 2022 project

How to use:
1. Extract the zip to a folder, open CorelCPG.sln with Visual Studio 2022.
2. Make sure Visual Studio has 'C++ desktop development' workload with v143 toolset, and 'C++ MFC/ATL' selected.
3. Ensure CorelDRAW X8 is installed and the path in app.cpp to VGCoreAuto.tlb is correct.
4. Build (Ctrl+Shift+B) and run. CorelDRAW must be running and a shape selected for the copy function to work.
